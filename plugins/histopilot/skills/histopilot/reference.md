# HistoPilot CLI reference

Generated by `scripts/skill_reference.py` from the code; do not edit by hand.
The contract behind it is `docs/cli-contract.md`.

## Commands

Every command takes `--json`, `--url`, `--project` and `--timeout SECONDS`. Commands that change records also take `--yes`, `--dry-run`, `--preview-hash HASH` and `--operation-id ID`; commands that start work take `--wait`; lists take `--limit` and `--offset`.

## Exit codes

| Exit | `error.kind` | Next move |
| --- | --- | --- |
| 1 | `internal` | Report it with the output. |
| 2 | `invalid` | Fix the command or spec. |
| 3 | `refused` | Change the request or the state first; resent unchanged, it fails again. |
| 4 | `conflict` | Reload or preview again, then retry. |
| 5 | `not-found` | Check the ID or tag. |
| 6 | `unavailable` | Start the service, fix --url, or sign in. |
| 7 | `unconfirmed` | Review data.preview, then rerun with --yes; a person approves a pending request with `histopilot confirm`. |
| 8 | `timeout` | Wait again, or rerun to replay. |
| 9 | `work-failed` | `histopilot tasks show`, then resume or retry. |
| 130 | `interrupted` | Rerun to replay. |

## Run states

Anything that runs carries `runState`: `queued`, `running`, `succeeded`, `failed`, `needs-attention`, `cancelled`, or `null` before it starts.
