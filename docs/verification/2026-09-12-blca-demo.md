# BLCA demo and workflow release verification

The default demo is now **BLCA demo**, a separate read-only walkthrough based on aggregate Bladder study structure. Its nine illustrative records span eight modules and 28 pages. All slide identifiers, scores, run histories, resource samples and artifact references are synthetic. The original research project was only inspected for aggregate structure; no individual records, images, feature tensors, checkpoints or prediction rows were copied.

| Package | Wheel resources and compiled assets match the current checkout; packaged demo loads independently of the checkout |

Browser verification uses the full React application and the packaged BLCA JSON through isolated in-browser API fixtures. Only project-list and demo-workspace reads are permitted; unexpected network requests fail the check. It starts no HistoPilot server. The README screenshot comes from this synthetic fixture.

The demo API was also checked in-process for authentication, restart/reload behavior, legacy demo compatibility, denial of local project mutations, scientific storage and compute launch, and preservation of unrelated local project state. It does not create a scientific project or convert synthetic references into executable files.

## Scientific and data checks

- 138 invented slide IDs: 62 development and 76 grade-2 test examples; development/test slide identities are disjoint. Patient identifiers are absent, and patient independence is explicitly unverified.
- Every development slide appears in exactly one assessment fold. Synthetic early stopping includes eight non-improving epochs; refit budgets derive from the best checkpoint epochs.
- Independent calculations agree with the released predictions for AUROC, average precision, accuracy, balanced accuracy, F1, log loss and confusion matrices. Displayed ROC area, calibration counts, Brier score and all 19 threshold/decision-curve points are consistent.
- All nonempty artifact references use `demo://`; no real filesystem paths, embedded slide pixels or scientific artifact payloads are included. Synthetic exports retain explicit synthetic and non-executable metadata.
- Test-cohort preparation remains independent of feature binding; the evaluation walkthrough explains feature matching.

Reproduce the browser check with `node scripts/verify-blca-demo.mjs` from `web/`, using a local Chromium installation (`HISTOPILOT_CHROMIUM` can specify its path). See [the demo guide](../BLCA_DEMO.md) for fixture regeneration and [deployment](../deployment.md) for manual server startup.

The HistoPilot server was not started or restarted. Production training and research artifacts were not modified. The build retains the existing large-JavaScript-chunk advisory; two dependency deprecation warnings occurred in the backend suite.
